# Grocery-Data-Management-system

A web-based Grocery Data Management System designed to manage grocery products, categories, prices, and inventory in an organized and efficient way.

## 🌐 Live Website

[Link] https://gregarious-pixie-82823d.netlify.app/

## 📌 Features

* Manage grocery products
* Display product categories
* Manage product prices
* Simple and user-friendly interface
* Organized grocery data management

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* MySQL

## 📂 Project

This project was developed as a practical web development project to demonstrate frontend development and grocery data management functionality.
